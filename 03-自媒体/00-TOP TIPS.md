# 核心要求
时长：6–10 分钟
要有活人感，避免大量使用纯AI（AI引导思路）
## 10分钟模版
1. 痛点引入（1 分钟）
	* 前30秒必须有冲突或结论
2. 核心方法讲解（6–7 分钟）
3. 一个真实案例（2 分钟）
4. 总结 + 下期预告（1 分钟）
# 核心主线
## 把自己当产品进行经营
1. 核心不是做自媒体、做视频
2. 构建个人品牌、个人影响力
```code
输入：兴趣 + 能力 + 市场需求
处理：内容输出
输出：信任 + 影响力 + 收入
```
## 公开经营过程
重点在于执行力，不是等成熟再开始构建
自媒体的内容就是整个经营过程，而是：
- 学习什么 → 讲什么
- 实践什么 → 分享什么
- 犯错什么 → 复盘什么
## 重点是内容构建，内容本身就是资产
> 前期不用重点关注与播放量，做的是“高价值垂直内容”。
1. 内容本身就是流量资产
2. 内容是个人能力展示、信任凭证、是广告
	* 未来的副业核心不是：广告\流量分成。而是：解决方案 + 咨询 + 项目合作
	* 产出的内容是视频，相当于：7×24 小时销售员、免费给别人做能力展示
3. 内容是未来产品的入口

# 内容分发模式
1️⃣ 录一个 15 分钟 B站视频  
2️⃣ 剪出 3 个 1 分钟观点  
3️⃣ 发到小红书  
4️⃣ 把逻辑整理成知乎文章
