## 二、技术架构可行性评估

### 2.1 整体架构设计
**结论**: **架构设计按照5层进行设计**，分别是**应用层、服务层、平台层、AI能力层、数据层**
讯飞重点关注和建设的为：**服务层、平台层、AI能力层**，详情参考:[[02-工作/工作周报/第4周20260119-0123/利川人寿工作量评估/利安人寿整体架构设计.canvas|利安人寿整体架构设计]]
**建议**:
* 整机基于讯飞已有的平台能力进行开发和复用
- 在服务层考虑增加监控组件：用户业务效果监控，用来评估整体建设成效
- 在Ai能力层增加安全组件：考虑大模型生成内容的安全，增加安全围栏

### 2.2 基础设施评估 
**评估结论**: **硬件资源基本满足，优化资源分配**

**现有资源**:
- 目前已提供的资料中明确已经有华为910B GPU × 2（按照单台8卡进行考虑，总计16卡），
- 同时2026年有追加采购计划

**资源分配建议**:

| 模块                | 资源需求    |
| ----------------- | ------- |
| 面客演练（星火陪练纯文字）     | 1-2卡    |
| 面见记录（ASR + 大模型总结） | 4-8卡    |
| 面客链接生成（智能体）       | 4-8卡    |
| 客户推荐（推荐模型）        | CPU资源即可 |

**风险提示**:
- 目前没有并发量需求没有明确，需要与客户明确业务并发情况后，重新调整资源分配
